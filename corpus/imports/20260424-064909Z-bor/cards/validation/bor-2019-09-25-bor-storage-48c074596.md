# Validation Card

## Metadata

- ID: `bor-2019-09-25-bor-storage-48c074596`
- Bug family: `input_validation_and_invariant_enforcement`

## What Confirmed The Issue

- Adds explicit checkpoint-only validation for beneficiary and nonce values in header verification.
- Changes checkpoint preparation to fetch the validator set for the boundary condition explicitly, sort it canonically, and fail if validators are unavailable.

## What Could Have Invalidated It

- Do not flag if the value is produced only by trusted local code and cannot be influenced across a protocol, RPC, or persistence boundary.
- Do not treat as exploitable if an earlier mandatory validation step rejects the malformed input before the sensitive sink.
