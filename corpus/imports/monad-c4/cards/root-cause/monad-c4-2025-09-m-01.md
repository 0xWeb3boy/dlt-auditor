# Root-Cause Card

## Metadata

- ID: `monad-c4-2025-09-m-01`
- Bug family: `signature_binding_and_signer_scope`
- Bug class: `signed-message-identity-misbinding`
- Confidence tier: `tier_a_confirmed`

## Missing Property

- Missing property: `identity-claim-signer-binding`

## Violated Invariant

- Invariant: When a signed p2p group-management message claims a validator_id or node_id, the recovered signing key must match the claimed identity before group state or peer-discovery state changes.

## Trust Boundary

- Boundary: peer message -> RaptorCast Secondary group state

## Attack Surface

- Entrypoint type: p2p group-management message handler
- Sensitive sink: group membership, pending confirms, and peer discovery updates

## Impact Pattern

- Primary impact: unauthorized-message-processing
- Secondary impact: p2p-denial-of-service
- Severity guide: medium

## Short Reusable Lesson

- RaptorCast verified that a message was signed, but did not bind the recovered signer to identity fields embedded in the message. Application-level group state was updated from claimed validator/node ids that could be attacker-chosen. Propagate the recovered signer to the secondary group handlers and fail closed unless validator_id/node_id and peer name records are bound to that signer and expected role.
