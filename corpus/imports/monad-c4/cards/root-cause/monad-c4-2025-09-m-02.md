## Missing Property

## Violated Invariant

- Invariant: Attacker-influenced bursts must not turn bounded queue backpressure into process panic; queue-full conditions should be handled as errors, drops, retries, or explicit flow control.

## Trust Boundary

- Boundary: peer forwarded transaction messages -> updater command executor

## Attack Surface

- Entrypoint type: TokioTaskUpdater executor command submission
- Sensitive sink: validator process liveness

## Impact Pattern

- Primary impact: node-crash
- Secondary impact: denial-of-service
- Severity guide: medium

## Short Reusable Lesson

- A bounded queue was present, but the queue-full path panicked. The resource limit became a crash primitive because attacker-influenced bursts could force try_send to return an error that was unwrapped with expect. Replace panic-on-full queue submission with explicit backpressure handling, bounded dropping, or recoverable error propagation; add tests that fill the command channel from attacker-like bursts.
