## Missing Property

## Violated Invariant

- Invariant: A trim/discard helper that preserves a partial page must write the preserved page back to the original page offset, not to an offset advanced for the later discard range.

## Trust Boundary

- Boundary: storage maintenance operation -> block-device write path

## Attack Surface

- Entrypoint type: block device trim/discard helper
- Sensitive sink: persistent storage page contents

## Impact Pattern

- Primary impact: storage-corruption
- Secondary impact: state-integrity
- Severity guide: medium

## Short Reusable Lesson

- The trim helper read a partial page at the original boundary, advanced the range to skip that page for discard, then wrote the preserved buffer using the advanced range offset. The preserved data could overwrite the next page. Write the partial page back before advancing the discard range, or save the original page offset in a separate variable and use it for pwrite; add unaligned trim regression tests.
