## Missing Property

- Missing property: `cross-layer-header-field-equality`

## Violated Invariant

- Invariant: Consensus-side block validation must reject a block whose consensus base_fee field disagrees with the execution header base_fee_per_gas that execution will later enforce.

## Trust Boundary

- Boundary: proposer block header -> consensus validation -> execution validation

## Attack Surface

- Entrypoint type: block header validation
- Sensitive sink: consensus block acceptance and execution static validation

## Impact Pattern

- Primary impact: consensus-execution-split
- Secondary impact: invalid-block-finalization
- Severity guide: medium

## Short Reusable Lesson

- The block carried two representations of base fee. Rust-side validation trusted the consensus header value for transaction checks and did not require equality with the execution header field, while C++ execution later rejected mismatches. Add an explicit Rust-side header validation check requiring consensus base_fee to equal execution base_fee_per_gas, including the pre-TFM default case, before block body fee checks or votes.
