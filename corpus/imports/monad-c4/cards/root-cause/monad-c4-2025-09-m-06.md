## Missing Property

- Missing property: `callback-coordinate-freshness`

## Violated Invariant

- Invariant: A delayed timer callback must not route or reschedule a newer stored vote using the stale coordinate attached to the old timer.

## Trust Boundary

- Boundary: consensus timer event -> vote routing state machine

## Attack Surface

- Entrypoint type: vote timer callback handler
- Sensitive sink: leader vote delivery and next timer scheduling

## Impact Pattern

- Primary impact: consensus-liveness
- Secondary impact: vote-misrouting
- Severity guide: medium

## Short Reusable Lesson

- The callback stored one coordinate in the timer event and another inside the pending vote. When the timer fired late, it dequeued the newer vote but routed it using the older timer round. Derive vote recipients and rescheduled timer coordinates from the stored vote round, and treat mismatched timer rounds as stale telemetry or no-op conditions.
