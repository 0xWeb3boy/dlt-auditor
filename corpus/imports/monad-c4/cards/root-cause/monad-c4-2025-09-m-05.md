## Short Reusable Lesson

- The debug raw receipt path serialized the inner receipt payload with plain RLP. Typed receipts need the EIP-2718 envelope byte, and a nearby raw transaction path already used encode_2718. Use encode_2718 for ReceiptEnvelope in raw/debug receipt APIs and test at least one legacy receipt plus each supported typed receipt against a standard decoder.
