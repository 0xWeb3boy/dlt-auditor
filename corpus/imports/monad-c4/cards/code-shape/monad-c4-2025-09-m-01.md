# Code-Shape Card

## Metadata

- ID: `monad-c4-2025-09-m-01`
- Bug family: `signature_binding_and_signer_scope`
- Bug class: `signed-message-identity-misbinding`

## Code Shape Summary

- Short description of what the buggy code looked like: RaptorCast verified that a message was signed, but did not bind the recovered signer to identity fields embedded in the message. Application-level group state was updated from claimed validator/node ids that could be attacker-chosen.

## Search Motifs

- signed envelope recovers author but inner validator_id or node_id drives state
- PrepareGroup, PrepareGroupResponse, or ConfirmGroup handler does not compare recovered key to payload identity
- group state keyed by claimed id instead of verified sender
- peer discovery records accepted from a message whose signer does not match listed peer

## Typical Asymmetry

- What was checked in one path but missing in another: signed envelope recovers author but inner validator_id or node_id drives state

## Patch Pattern

- What the fix changed structurally: Propagate the recovered signer to the secondary group handlers and fail closed unless validator_id/node_id and peer name records are bound to that signer and expected role.

## False Match Warnings

- No issue if the router passes the recovered author into every final state mutation and the handler compares it to each claimed identity
- No issue if only authenticated validators can reach the handler and membership is checked before side effects
- Impact is lower if group state is advisory, isolated per connection, or rate-limited without affecting block propagation
