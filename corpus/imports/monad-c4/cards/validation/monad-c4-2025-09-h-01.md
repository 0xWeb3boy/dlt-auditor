# Validation Card

## Metadata

- ID: `monad-c4-2025-09-h-01`
- Bug family: `resource_accounting_and_limits`
- Bug class: `legacy-gas-cost-underaccounting`

## What Confirmed The Issue

- Evidence 1: The report shows the vulnerable helper computing gas_bid as min(max_fee, base_fee + priority_fee) for every TxEnvelope.
- Evidence 2: The execution-layer excerpt treats legacy transactions differently and consumes the whole gas price.
- Evidence 3: Current upstream block policy has an explicit legacy/EIP-2930 branch before EIP-1559 math.

## What Could Have Invalidated It

- Compensating control 1: A canonical shared gas-cost helper is used by txpool, block policy, block validation, and execution.
- Compensating control 2: All pre-EIP-1559 transaction types are rejected before this helper runs.

## Severity Guidance

- Expected impact band: consensus-liveness
- Expected severity band: high

## False-Positive Cautions

- Caution 1: No issue if legacy and EIP-2930 transactions use a separate full-gas-price branch before EIP-1559 math
- Caution 2: No issue if execution and block policy call the same type-aware helper or share conformance tests
- Caution 3: Impact is lower if invalid transactions are rejected or evicted before block proposal and cannot be repeatedly selected
